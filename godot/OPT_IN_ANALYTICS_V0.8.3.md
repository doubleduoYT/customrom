# Overuse Controller v0.8.3-alpha — 동의 기반 사용 습관 통계

상태: **실험용 구현 / 실기기 검증 전 정식 배포 금지**.
기반 브랜치: `feature/v0.8.2-picker-safety`.
`main`과 선행 PR 브랜치는 변경하지 않음.

## 목적

스마트폰을 얼마나 오래 사용했는지 외에도, 선택한 오락 앱을 떠났다가 다시 실행하는 빈도를 파악하여 **이후 자발적인 사용 중단 효과 검증을 위한 자료**를 만든다.

앱 이탈은 사용자가 직접 중단한 것일 수도 있고, 알림·전화·작업 전환으로 발생했을 수도 있다. 따라서 **'관찰된 앱 이탈' = '자발적 중단' 또는 '개입 효과'가 아니다.**

## 이번에 구현한 기능

- Android 선택형 개입 모드에서 오늘의 **대상 앱 화면 사용 시간**, **다른 앱 사용 시간**, **실제 화면 OFF 시간**을 각각 표시한다. 앱이 불명확하거나 권한이 없으면 다른 앱 사용 시간으로 추정해 넣지 않는다.
- 별도 **'선택한 앱 사용 통계 기록 (동의)'** 토글, 기본 **OFF**.
- 동의 + 선택형 모드 + 사용기록 접근 허용 + 모니터링 실행 중인 경우에만 대상 앱별 데이터를 집계한다.
- 대상 앱별로 아래 항목만 저장한다.
  - 해당 앱 관찰 사용 시간(ms)
  - 1~5단계에 해당하는 시간(ms): 실제 블러가 눈에 보였음을 보장하지 않음
  - **관찰된 이탈 횟수**: 대상 앱에서 확실히 다른 앱으로 전환한 횟수 (화면 꺼짐·일시정지·권한 오류는 제외)
  - **5분 이내 재진입 횟수**: 앱 이탈 후 같은 대상 앱으로 다시 들어온 횟수
- 하루 단위로 자동 초기화. 앱별 집계 데이터는 최대 30개 대상 패키지와 요약 수치로 제한.
- 모든 앱별 통계는 기기의 SharedPreferences에만 저장. 화면 캡처, 개인 메시지, 앱 사용 시간별 타임라인, 키 입력 또는 GPS 정보는 수집하지 않는다.
- **사용 기록 삭제**: 확인 대화상자를 통해 모든 앱별 통계 즉시 삭제.
- **오늘의 사용 기록 공유하기**: 사용자가 직접 누를 때만 Android 공유 시트 호출. 공유할 경우 **패키지 이름과 집계 기록이 선택한 외부 앱으로 전달**될 수 있다.
- 토글을 OFF로 바꾸면 새 기록 수집을 중단하지만 기존 앱별 집계 기록은 수동 삭제 전까지 남는다.
- Windows 버전은 기존 v0.8.2 기능 유지. 앱별 기록 기능은 아직 Android 전용.

## 관찰 알고리즘

1. 사용자가 선택형 개입을 켜고 대상 앱과 Usage Access 권한을 설정한다.
2. 전면 앱을 확실히 확인할 수 있을 때만 앱별 사용 시간을 누적한다.
3. **대상 앱 → 알려진 다른 앱**으로 바뀌면 이탈을 1회 기록한다.
4. 그 후 같은 앱에 **5분 이내** 돌아오면 재진입을 기록한다.
5. 화면이 꺼지거나 전면 앱이 불명확해지거나 권한이 사라지거나 모니터링이 일시정지되면 이탈 추론을 중단한다. **그 상태를 자발적 종료로 집계하지 않는다.**
6. 일일 경계는 기기의 로컬 날짜로 결정한다. 1초 샘플링 오차와 OS 이벤트 지연으로 정확한 Digital Wellbeing 사용 시간과 다를 수 있다.

## 사용자 경험 및 안전 원칙

- Android의 루팅 CPU 제한과 전체 화면 Blur는 여전히 별도 선택 기능이며, **기본값 OFF**.
- 앱 통계 기능을 끄거나 기록을 지워도 Overuse Controller의 기본 단계, 일시정지, 화면 효과 동작에는 영향을 주지 않는다.
- 전화, 메시지, 설정, 지도 등 보호 앱 정책은 v0.8.2 그대로 유지.
- 저장된 패키지명은 사용자가 동의한 개입 대상 앱을 식별하는 데 사용하며 원격 서버로 자동 전송하지 않는다.
- 실제 시험 시 '스마트폰 사용 감소 효과'를 증명하려면 대조군 및 참가자 동의 기반 비교 실험이 별도로 필요하다.

## 자동 검사

`UsageAnalyticsTest.java`는 다음을 검증한다.

- 통계 OFF에서 기록 미생성
- 단계별 누적 시간과 단계 도달 시간 집계
- 확실한 앱 전환에서만 이탈 1회, 5분 내 재진입 1회
- 권한/전면 앱 불명/화면 OFF/일시정지에서 잘못된 이탈 방지
- 앱을 바꿔가며 사용하는 전환 A→B→A
- 재진입 5분 초과 제외
- 저장/복원, 자정 초기화, 삭제, 잘못된 파일 복구, 시간 상한

CI는 기존 Android 네이티브/Java 보호정책/Godot 스모크·회복/앱 선택기/Android ARM64 및 Windows x64 빌드도 계속 실행한다.

## 실제 기기에서 확인할 것

- [ ] 사용기록 권한이 없는 상태에서 수집이 중지되고 선택형 오버레이도 제거되는지
- [ ] 선택한 게임 3분 → 다른 앱 1분 → 게임 복귀 시 앱별 시간/이탈/재진입이 올바른지
- [ ] 게임 중 화면을 끌 때 이탈이 잘못 증가하지 않는지
- [ ] 15분 일시정지/종료/서비스 재시작 시 중복 카운트가 없는지
- [ ] 5분을 넘긴 복귀와 여러 대상 앱 사이를 오갈 때의 오차
- [ ] 통계를 끄면 새로운 앱별 기록이 생성되지 않고, 삭제하면 복원되지 않는지
- [ ] 사용자가 공유 버튼을 눌렀을 때만 OS 공유 UI가 표시되는지
- [ ] Android 11 및 Android 12+에서 기존 Blur와 앱별 개입 기능의 안전한 회귀
- [ ] 삼성·AOSP 제조사별 앱 전환/권한 철회 이벤트 정확도
- [ ] Windows 기존 성능 제한·오버레이 기능의 회귀
